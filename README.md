# kubstu_timetable_tgbot
Официальный телеграмм бот с расписанием пар для студентов КубГТУ.

Бот может показывать расписание на сегодня (`/today`), завтра (`/tomorrow`) и ближайший учебный день (`/nearest`). Есть возможность посмотреть расписание на ближайшие 2 недели (для ОФО)/полностью (для ЗФо) (`/showall`). Если требуется узнать расписание в определённый день недели или в определённую дату, это тоже возможно (кнопка "Выбрать день" в меню).

Можно посмотреть список экзаменов (`/exams`) и список дисциплин с преподавателями в текущем семестре (`/teachers`).

Каждую среду и субботу расписание автоматически сохраняется в базу данных, что делает работу бота независимой от работы сайта/API. На основе расписания всех групп составляется расписание преподавателей, которое можно посмотреть, выбрав меню "Расписания преподавателей" и выбрав нужного преподавателя. Если этот преподаватель не ведёт пары в группе - это не проблема. Просто введите его полное ФИО без ошибок и с большой буквы.

Присутствует почти полная поддержка групповых чатов, поэтому бота можно добавлять в чат группы, оповещая всех командой `/today` в 5 утра, что сегодня к первой паре. Если включить уведомления, бот в конце пар будет сам в личные сообщения отправлять расписание на следующий день (если завтра есть пары).

Присутствует кастомизация: можно убрать эмодзи на кнопках и убрать некоторые кнопки из меню, сделав интерфейс ещё более минималистичным.

[Ссылка на бота](https://t.me/kubstu_timetable_bot)

## Как запустить самостоятельно?

- Получите токен у [@BotFather](https://t.me/BotFather).
- Создайте файл `.env`
```
TOKEN="токен бота (получен выше)"
MONGO_URI="uri базы данных монги"
KUBSTU_API="API КубГТУ"
```

- Скачайте все библиотеки командой `npm i`
- Скомпилируйте бота `npx tsc`
- Запустите бота с помощью `npm start`
