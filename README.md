# kubstu_timetable_tgbot
Телеграмм бот с расписанием пар для студентов КубГТУ.

Бот может показывать расписание на сегодня (`/today`), на завтра (`/tomorrow`) и, если у вас начались выходные, на ближайший учебный день (`/nearest`). Есть возможность посмотреть полное расписание (`/showall`) или посмотреть расписание на конкретный день. Можно посмотреть список экзаменов (`/exams`) и список дисциплин с преподавателями в текущем семестре (`/teachers`).

Бот на основе расписания всех групп может составить расписание преподавателя, что может быть очень полезным во время зачётной недели и не только.

Расписание автоматически в каждую среду и субботу полностью сохраняется в базу данных. Присутствует почти полная поддержка групповых чатов, поэтому бота можно добавлять в ваш студенческий чат, оповещая всех в 5 утра, что сегодня к первой паре. Если включить уведомления, бот в конце пар будет сам отправлять расписание на следующий день (если завтра есть пары).

[Ссылка на бота](https://t.me/kubstu_timetable_bot)

## Как запустить самостоятельно?

- Получите токен у [@BotFather](https://t.me/BotFather).
- Создайте файл `.env`
```
TOKEN="токен бота (получен выше)"
MONGO_URI="uri базы данных монги"
KUBSTU_API="API КубГТУ"
```

- Скачайте все библиотеки командой `npm i`
- Скомпилируйте бота `npx tsc`
- Запустите бота с помощью `npm start`
